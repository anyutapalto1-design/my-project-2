# my-project-2: анализ переписок Telegram

Два скрипта:

- `tg_export.py` выгружает диалоги из вашего аккаунта Telegram в JSON.
- `analyze.py` строит по выгрузке отчет и сохраняет переписку компактным текстом.

## ⚠️ Приватность

Этот репозиторий **публичный**. Переписки, `result.json` и файл `*.session` в него
класть нельзя. `.gitignore` уже исключает `exports/`, `reports/`, `transcripts/`,
`result.json` и `*.session`, но перед `git add` всё равно смотрите `git status`.

Файл `tg_export.session` дает полный доступ к вашему аккаунту. Никому его не
передавайте. После выгрузки удалите его или завершите сеанс в Telegram:
«Настройки → Устройства».

## Шаг 1. Выгрузить переписку

### Вариант А: Telegram Desktop (без кода)

1. Telegram Desktop → «Настройки → Продвинутые настройки → Экспорт данных из Telegram».
2. Отметьте «Личные чаты» (и группы, если нужны), формат **JSON**, медиафайлы можно не включать.
3. В папке экспорта появится `result.json`.

Один чат можно выгрузить отдельно: откройте его → ⋮ → «Экспорт истории чата» → JSON.

### Вариант Б: скрипт `tg_export.py`

Подходит, если нужно выгружать регулярно или выборочно.

1. Зайдите на https://my.telegram.org → API development tools и создайте приложение.
   Получите `api_id` и `api_hash`.
2. Установите зависимости и запустите:

```bash
pip install -r requirements.txt
export TG_API_ID=123456 TG_API_HASH=ваш_hash

python tg_export.py --list                       # список диалогов и их id
python tg_export.py --chat "Маша" --chat 123456  # выбранные диалоги
python tg_export.py --personal --since 2025-01-01 # все личные чаты с даты
```

Если переменные не заданы, скрипт спросит ключи сам. При первом запуске он
также спросит номер телефона и код из Telegram. Файлы
появятся в `exports/`.

## Шаг 2. Отчет

```bash
python analyze.py exports/                       # отчет по всем выгрузкам
python analyze.py result.json --chat Маша -o reports/masha.md
python analyze.py result.json --top 5 --transcript transcripts/
```

В отчете:

- период переписки, число сообщений и активных дней;
- по каждому участнику: доля сообщений, средняя длина, кто чаще начинает
  разговор, медианное время ответа, стикеры, голосовые и фото;
- активность по часам, дням недели и месяцам;
- самая долгая пауза и частые слова каждого участника.

`--transcript` сохраняет переписку текстом вида `2025-03-04 11:03 Имя: сообщение`.
В этом виде ее удобно отдать Claude для смыслового разбора: темы, тон,
динамика отношений, договоренности, нерешенные вопросы.

Все параметры: `python analyze.py --help`, `python tg_export.py --help`.
